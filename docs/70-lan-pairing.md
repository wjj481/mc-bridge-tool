# 70 · 局域网连接码远程控制（手机/iPad 网页面板）

> v1.2.0 新增。用手机浏览器（iPhone Safari / 安卓 Chrome）在**同一 Wi-Fi** 下远程管理服务器，无需装原生 App。

---

## 这是什么？

桌面端内置一个轻量 WebAPI（`mcbridge/webapi.py`）。开启后，任何同局域网的手机浏览器都能通过 **6 位数字连接码** 配对，然后在网页上：

- 看服务器运行状态、在线玩家、内存、端口监听
- 一键 启动 / 停止 / 重启
- 实时滚动日志
- 修改配置（MOTD、难度、游戏模式、最大玩家、内存等）

iOS / iPadOS 因为沙盒限制不能跑 JVM，这套网页远程控制就是 iPhone 上的主要用法。

---

## 3 步上手

### 1. 桌面端开启

打开桌面端 → 进入「③ 控制 / 监控」页 → 拉到底部「远程控制」区块 → 点 **「启动远程控制」**。

开启后会显示：

| 信息 | 说明 |
|------|------|
| 局域网地址 | 形如 `http://192.168.x.x:8765` |
| 连接码 | 6 位数字（大字显示，如 `482913`） |
| 二维码 | 手机相机直接扫 |

连接码默认 **5 分钟有效**，点「换个码」可立即换新码；重启桌面端后旧码全部失效。

### 2. 手机连同一 Wi-Fi

手机必须和电脑连**同一个路由器 / 同一个局域网**。跨公网、不同 Wi-Fi 是连不上的（这是安全设计）。

### 3. 连接

两种方式任选：

- **扫码**：用手机相机扫桌面端二维码，会自动打开网页面板并带上连接码，点「连接」即可。
- **手动**：打开 webui 网页（部署在 Netlify 的地址，或本地 `webui/`），手动输入 6 位码，或展开「高级」填电脑的局域网 IP。

连接成功后网页自动保存登录态（token 存浏览器本地），下次打开直接进控制台。

## 网页面板（webui/）

`webui/` 是纯静态页面，可部署到 Netlify：

1. 打开 [Netlify Drop](https://app.netlify.com/drop) ，把 `webui/` 目录拖进去；
2. 或连接 GitHub 仓库，Publish directory 填 `webui`；
3. 拿到一个 `https://xxx.netlify.app` 地址，手机 Safari 打开 → 分享 →「添加到主屏幕」，就像一个 App。

详见 [webui/README.md](../webui/README.md)。

## 安全说明

- 连接码是**一次性临时密钥**，只在局域网内有效，不暴露公网。
- WebAPI 默认只监听本机探测到的局域网网卡，不监听公网。
- 配对成功后下发 24 小时 token；点「断开」或清浏览器数据即失效。
- 在「远程控制」区块可开启 **「人工允许接入」**：新设备发来的连接码请求会先挂起，等你在桌面端点「允许」才放行，适合不信任访客网络时使用。
- **不要**把 8765 端口直接映射到公网；需要外网远程请自行加 VPN / Tailscale 等隧道。

## 常见问题

**Q：手机连不上？**
- 确认手机和电脑同一 Wi-Fi；
- 确认电脑防火墙放行了 8765 端口（首次启动 Windows 可能弹窗，点允许）；
- 确认桌面端「远程控制」仍在运行，连接码未过期。

**Q：连接码过期了？**
- 桌面端点「换个码」重新生成，手机重新输入即可。

**Q：能在外网用吗？**
- 不能直接用。本功能只设计在局域网工作。需要外网请配合 Tailscale / ZeroTier 等组网工具，把电脑和手机组进同一个虚拟局域网。
