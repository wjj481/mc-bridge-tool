# 20 · 网络与端口配置

开好服之后，别人怎么连进来？本篇讲清楚端口、防火墙、局域网、公网、路由器映射。

---

## 端口一览

本工具默认互通服务器占两个端口：

| 用途 | 协议 | 默认端口 | 说明 |
|------|------|----------|------|
| Java 版玩家连接 | **TCP** | 25565 | 电脑版 / 启动器连的 |
| 基岩版玩家连接 | **UDP** | 19132 | 手机、平板、主机、Win10 版连的 |

> 两个协议不一样！防火墙和路由器上要分别放行，不能只开一个。

---

## 一、本机防火墙放行

### Windows

1. 打开「Windows  Defender 防火墙」→「高级设置」→「入站规则」
2. 新建规则 → 端口 → TCP，特定本地端口填 `25565` → 允许连接
3. 再建一条 → UDP，特定本地端口填 `19132` → 允许连接
4. 名字随便起，比如 `MC-Java`、`MC-Bedrock`

> 也可以更省事：第一次启动服务端时 Windows 会弹窗问「是否允许 Java 联网」，勾选「专用网络」点允许即可，Windows 会自动帮你放行。

### macOS

系统设置 → 网络 → 防火墙。如果防火墙是开着的，在「选项」里把 Java 加入允许列表，或者临时关掉防火墙测试一下。

### Linux（ufw 为例）

```bash
sudo ufw allow 25565/tcp
sudo ufw allow 19132/udp
sudo ufw reload
```

如果用 firewalld：

```bash
sudo firewall-cmd --permanent --add-port=25565/tcp
sudo firewall-cmd --permanent --add-port=19132/udp
sudo firewall-cmd --reload
```

## 二、局域网联机（同一个 Wi-Fi 下）

这是最简单的场景，不需要公网 IP，也不需要端口映射。

### 1. 查到开服电脑的局域网 IP

- **Windows**：`ipconfig` → 找「IPv4 地址」，通常是 `192.168.x.x` 或 `10.0.x.x`
- **macOS**：系统设置 → 网络 → 详细信息 → IP 地址
- **Linux**：`ip addr` 或 `hostname -I`

假设开服电脑 IP 是 `192.168.1.10`。

### 2. 朋友连进来

- **Java 版**：多人游戏 → 添加服务器 → 地址填 `192.168.1.10:25565`
- **基岩版（手机）**：见 [30-connect-bedrock.md](30-connect-bedrock.md)，地址填 `192.168.1.10`，端口填 `19132`

### 3. 连不上排查清单

1. 两台设备连的是**同一个 Wi-Fi / 同一个路由器**吗？
2. 开服电脑的防火墙放行 25565/TCP 和 19132/UDP 了吗？
3. 服务器真的启动完成了吗？（日志里要有 `Done!`）
4. 路由器开了「AP 隔离 / 客户端隔离」吗？有些路由器默认开启，会导致同 Wi-Fi 设备互相看不见，需要在路由器后台关掉。

## 三、公网联机（外面的朋友也能连）

让不在你家 Wi-Fi 下的朋友也能进服，需要做两件事：**拿到公网 IP** + **路由器端口映射**。

### 1. 你有没有公网 IP？

在开服电脑浏览器搜「我的 IP」，看到一个 IP。然后登录路由器后台（通常是 `192.168.1.1`），看 WAN 口获取到的 IP：

- **两个 IP 一样**：你有公网 IP，可以直接做端口映射
- **两个 IP 不一样**：你在运营商大内网里（CGNAT），普通端口映射没用，需要：
  - 打运营商客服电话，要求「开通公网 IP」（电信 / 联通一般免费给，移动可能要套餐）
  - 或者用内网穿透工具（见下文）

### 2. 路由器端口映射（虚拟服务器）

登录路由器后台，找到「虚拟服务器 / 端口转发 / 端口映射」（不同品牌叫法不同），添加两条规则：

| 名称 | 外部端口 | 内部端口 | 内部 IP（开服电脑的局域网 IP） | 协议 |
|------|----------|----------|--------------------------------|------|
| MC-Java | 25565 | 25565 | 192.168.1.10 | TCP |
| MC-Bedrock | 19132 | 19132 | 192.168.1.10 | UDP |

保存后重启路由器（有些路由不重启不生效）。

### 3. 朋友怎么连

- 把你的公网 IP 告诉朋友。他们在**外网**环境（比如手机用 4G 流量）测试连接。
- Java 版地址：`你的公网IP:25565`
- 基岩版：服务器地址填你的公网 IP，端口 `19132`

> 公网 IP 每次拨号会变（动态 IP），如果想让朋友长期记住一个地址，可以用 DDNS 域名（路由器后台自带花生壳 / no-ip 之类的功能）。

### 4. 安全提醒

- 开服后 `online-mode` 建议保持开启（正版验证），否则任何人都能冒充用户名进来。
- 不要把 `ops.json`、`server.properties` 里的敏感信息公开。
- 定期看日志，发现可疑 IP 用 `/ban-ip` 封禁。

## 四、没有公网 IP？用内网穿透

如果你没法拿到公网 IP，可以用内网穿透工具把本地端口暴露到公网。常见方案：

- **cpolar / 花生壳**：有免费额度，配置简单，适合小圈子朋友联机
- **frp**：需要自己有一台有公网 IP 的云服务器，免费且稳定
- **SakuraFrp / OpenFrp**：国内免费 frp 面板

注意：frp 类工具默认只转发 TCP。基岩版 19132 是 **UDP**，需要确认穿透方案支持 UDP 转发，否则手机基岩版玩家连不上。

## 五、端口被占用怎么办

如果启动时报 `Address already in use` 或 `绑定端口失败`：

1. 说明 25565 或 19132 已经被别的程序占了。
2. Windows 查占用：
   ```
   netstat -ano | findstr :25565
   ```
3. 不想杀那个程序的话，直接在 MC Bridge Tool 的配置页把 Java 端口改成别的（比如 25566），基岩端口也跟着改（比如 19133），连的时候朋友地址后面跟新端口即可。
