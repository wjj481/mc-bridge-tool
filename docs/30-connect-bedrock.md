# 30 · 基岩版（手机 / 平板）怎么加服务器

本篇教你在 iPhone / iPad / 安卓手机 / Win10 基岩版 / 主机上，通过 Geyser 连接你搭好的互通服。

---

## 前提

- 服务端已经启动成功（日志里有 `Done!`）
- 基岩版 UDP 端口 19132 已在防火墙放行
- Floodgate 插件已安装（本工具一键部署时自动装了）
- 你知道服务器的 IP 地址（本机测试用 `localhost`，局域网用开服电脑的局域网 IP，公网用公网 IP）

---

## 一、iPhone / iPad（iOS 版 Minecraft）

> 📌 iPhone / iPad 是**客户端**，用来进别人开的服是完全没问题的。只是它自己不能当服务器开服，见 [40-faq.md](40-faq.md)。

### 步骤

1. 打开 Minecraft（基岩版 / Bedrock Edition），登录你的 Xbox 账号。
2. 主界面点 **「Play / 游玩」**。
3. 切换到 **「Servers / 服务器」** 标签。
4. 拉到最下面，点 **「Add Server / 添加服务器」**。
5. 填写：
   - **Server Name / 服务器名称**：随便起，比如「我的互通服」
   - **Server Address / 服务器地址**：填开服电脑的 IP
     - 本机同机测试：填你电脑的局域网 IP（不要填 `localhost`，手机上 localhost 是手机自己）
     - 例：`192.168.1.10`
   - **Port / 端口**：`19132`
6. 点 **「Save / 保存」**。
7. 服务器列表里就会出现你刚加的服，点进去即可。

---

## 二、安卓手机

操作和 iOS 几乎一样：

1. 打开 Minecraft（基岩版）
2. 点「Play / 游玩」→「Servers / 服务器」
3. 滑到底部「External Servers / 外部服务器」→「Add Server」
4. 填服务器地址（局域网 IP，如 `192.168.1.10`）和端口 `19132`
5. 保存后点进游戏

---

## 三、Win10 / Win11 基岩版 / Xbox / 主机

1. 启动 Minecraft 基岩版
2. 「Play」→「Servers」→「Add Server」
3. 地址填 IP，端口 `19132`
4. 加入

> 注意：**Java 版客户端和基岩版客户端不能混着加服**。Java 版玩家在「多人游戏」里用 `IP:25565` 连；基岩版玩家在「Servers」里用 IP + 端口 `19132` 连。两边进的是同一个世界。

---

## 四、连不上怎么办

按顺序排查：

### 1. 服务器真的在跑吗？

在 MC Bridge Tool 主界面看状态灯，必须是 🟢 绿色。日志里要有 `Done (x.xxxs)!`。

### 2. 端口对吗？

- Java 版玩家连的是 **25565 TCP**
- 基岩版玩家连的是 **19132 UDP**
- 手机上不要在地址后面加 `:25565`，而是单独填端口 `19132`

### 3. 防火墙放行 UDP 了吗？

很多人只放了 TCP 25565 就以为行了，基岩版是 UDP 19132，两个都要放。看 [20-network.md](20-network.md)。

### 4. 手机和电脑在同一个 Wi-Fi 吗？

局域网测试时，手机不要用 4G/5G 流量，要和开服电脑连同一个 Wi-Fi。

### 5. 路由器 AP 隔离

有些路由器默认开启「AP 隔离」，导致 Wi-Fi 设备互相 ping 不通。登录路由器后台，把「AP 隔离 / 客户端隔离 / 用户隔离」关掉。

### 6. Floodgate 没装？

如果你看到基岩版玩家连进去后立刻被踢、提示要登录正版账号，说明 Floodgate 插件没启用。检查服务器 `plugins/` 目录下有没有 `floodgate-spigot.jar`，以及 MC Bridge Tool 配置里 `Floodgate 允许基岩版加入` 开关是不是打开了。

### 7. 在线模式和 Floodgate 的关系

- `online-mode=true`（正版验证开）：Java 版玩家必须正版账号；基岩版玩家通过 Floodgate 免正版验证加入
- `online-mode=false`（离线模式）：所有人都能进，但**存在被人冒充用户名的风险**，仅建议小圈子信任环境使用

本工具一键部署默认 `online-mode=true`，你可以在配置页改。

## 五、常见提示

| 提示 | 原因 | 解决 |
|------|------|------|
| 「Unable to connect to world」 | IP 填错 / 服务器没开 / 防火墙挡了 | 对照上面 1~4 步排查 |
| 「Outdated server!」 | 手机 Minecraft 版本比服务端新 | 手机里把 Minecraft 更新到最新，或在工具里把 Paper 降到对应版本 |
| 「Outdated client!」 | 手机版本太旧 | 应用商店更新 Minecraft |
| 进去就被踢 / 提示要登录 | Floodgate 没装或没启用 | 重新一键部署 / 检查插件目录 |
| 能进但延迟很高 | 跨网络 / 跨运营商 | 尽量和朋友同网络，或用更快的联机方案 |
